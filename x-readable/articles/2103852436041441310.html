用 Opus 5.5 当周末产品经理：周一前大幅改进 App

作者：@HHaandr（Hendrik Haandrikman 🐈）
原文：https://x.com/HHaandr/status/2103852436041441310

Got Opus 5.5 tokens to burn this weekend?

这个周末 Opus 5.5 token 用不完？

Turn Claude into your app's product manager. It'll use your app like a new user, dig through your real revenue + App Store numbers, and show you exactly where you're losing people

把 Claude 变成你应用的产品经理。它会像新用户一样用你的应用，翻真实收入和 App Store 数据，精确指出你在哪里流失用户。

WILDLY better app by Monday. Here's how 👇

周一前应用会好很多。做法如下 👇

Step 0 (do this now, Apple takes 24–48h to generate your first analytics reports):

第 0 步（现在就做，苹果生成首批分析报告要 24–48 小时）：

・ brew install asc

brew install asc

・ Create an App Store Connect API key (Admin role), then asc auth login

创建 App Store Connect API 密钥（Admin 角色），然后 asc auth login

・ Ask Claude to request your App Store analytics reports

让 Claude 申请你的 App Store 分析报告

・ Open your app's folder in Claude Code (Code tab in the Claude desktop app)

在 Claude Code 中打开应用文件夹（Claude 桌面端的 Code 标签）

・ Connect the RevenueCat plugin

连接 RevenueCat 插件

・ Paste this:

粘贴这段：

"Act as a world-class mobile product manager reviewing {app name}, my app that helps {who} {do what}

「扮演世界级移动产品经理，评审 {app name}——帮助 {who} {do what} 的应用

Build and run it in the iOS Simulator. Go through it like a first-time user: onboarding, core feature, paywall. Screenshot every bit of friction

在 iOS 模拟器里构建并运行。像首次用户一样走完：onboarding、核心功能、付费墙。每处摩擦都截图

Pull the last 90 days from RevenueCat (trials, trial conversion, churn, revenue) and App Store Connect via asc (impressions, product page views, downloads), plus recent App Store reviews

从 RevenueCat 拉近 90 天（试用、试用转化、流失、收入），经 asc 从 App Store Connect 拉展示、产品页浏览、下载，以及近期评论

Find the biggest leak in the funnel: from store page to download to trial to paid to renewal

找到漏斗最大漏洞：商店页→下载→试用→付费→续订

Propose 3 iterations: one that makes it easier to use, one that brings people back, one that converts more to paid. For each: the evidence, the change, the metric it should move, the effort

提出 3 个迭代：一个更易用、一个提升回访、一个提升付费转化。每个写清：证据、改动、应拉动的指标、工作量

Put it all in one dashboard. Don't touch the code yet."

全部放进一个仪表盘。先别改代码。」

・ Pick your favorite and tell Claude to build it

挑一个最喜欢的，让 Claude 去实现

If you're in a rush and feeling adventurous, I can confirm this'll also work if you have the Claude Chrome plugin, log into App Store Connect, and tell it to look up the data there

如果赶时间又想冒险：有 Claude Chrome 插件、登录 App Store Connect，让它直接在那里查数据，我也确认可行。
