把一个视觉概念用到真实目录上

I saw a clothing-store concept by @cambreedesigns on X. Garments hang sideways on a rail. Hovering makes room between their neighbors and turns the selected item toward you. The interaction borrows a familiar action from a physical shop: move things aside to inspect one.

我在 X 上看到 @cambreedesigns 的一个服装店概念：衣服侧挂在一根杆上。悬停时，相邻衣物会让出空隙，被选中的那件转向你。这种交互借用了实体店里很熟悉的动作：把旁边的东西拨开，细看其中一件。

I often look for ways to apply a strong visual idea to a real business. For this experiment I chose Molimao Sarajevo, a local clothing brand. I live in Bosnia and like building my experiments with its brands and places. Their existing product photos gave the concept a concrete test: preserve a recognizable garment while making it interactive.

我常常想办法把一个强烈的视觉想法用到真实生意上。这次实验我选了当地服装品牌 Molimao Sarajevo。我住在波斯尼亚，喜欢用这里的品牌和地点来做实验。他们已有的产品照片给了这个概念一次具体检验：既要保住能认出来的衣服，又要让它可交互。

为什么用视频而不是 3D

The display needed photographic product detail: fabric, cut and print. I considered 3D, but building garment models and materials for the entire catalog would have added a separate production process. I also wanted to avoid a simplified render changing how the product looked. For this experiment, working from photographs kept the production focused on the existing products.

这个陈列需要照片级的产品细节：面料、剪裁和印花。我考虑过 3D，但为整个目录建模和做材质会再多出一条制作流程。我也不希望简化后的渲染改变产品看起来的样子。对这次实验来说，从照片出发，能让制作始终围绕现有产品。

I had already tested a frame-based approach in another clothing showcase. Generate a fixed movement, split it into images, then let code decide which image to show. A locked camera and one quarter-turn fit this approach: the two orientations covered the interaction I wanted.

我在另一个服装展示里已经试过基于帧的做法：生成一段固定运动，拆成图片，再由代码决定显示哪一张。锁定相机、只做四分之一圈旋转，正好适合这个方法：两个朝向就覆盖了我要的交互。

We started with Molimao’s white “Before” T-shirt. I set the visual and interaction criteria, selected outputs and reviewed each iteration. In Codex, the agent prepared assets, ran generation through an API, processed the footage and built the interface. We proved the sequence on one product before expanding it.

我们从 Molimao 的白色 “Before” T 恤开始。我设定视觉和交互标准，挑选输出，并审看每一轮结果。在 Codex 里，agent 准备素材、通过 API 生成、处理影像并搭建界面。我们先在一件产品上验证完整流程，再扩展。

The initial layout missed that shared-rail behavior. I made the motion requirements explicit so that the generated footage and the interface would obey the same rules.

最初的布局没有做出那根共用衣杆的行为。我把运动要求写明确，好让生成的影像和界面遵守同一套规则。

运动约定：一件衣服，一根悬挂轴

  • 01 / Rest — Strict profile: Exactly side-on, with no three-quarter turn toward the camera.
    01 / 静止——严格侧面：完全侧对镜头，不要有转向镜头的四分之三侧面。
  • 02 / Hover — One 90° turn: Garment and wooden shoulders rotate together. Neighbors slide aside without dimming.
    02 / 悬停——一次 90° 旋转：衣服和木衣肩一起转。相邻衣物让开，但不变暗。
  • 03 / Selection — Front view: Leaving reverses the turn. Clicking opens the product view.
    03 / 选中——正面：离开时反向转回。点击打开产品页。

03 The vertical wire stays fixed. Only the wooden shoulders and garment belong to the animated frames.

03 竖直的挂线保持不动。只有木衣肩和衣服属于动画帧。

准备图像锚点，并把 LTX 接到 Codex

Catalog photos establish identity: shape, fabric color and the position of the print. The animation needs that product in two matched poses. I used the built-in image-generation tool in Codex, which I referred to as GPT Images 2 (Google’s Nano Banana Pro or Nano Banana 2.1 can also be used for this step): first a front view on wooden shoulders, then a strict profile derived from that accepted image.

目录照片确立身份：外形、面料颜色和印花位置。动画需要同一件产品的两个匹配姿态。我用了 Codex 内置的图像生成工具，我称之为 GPT Images 2（这一步也可以用 Google 的 Nano Banana Pro 或 Nano Banana 2.1）：先做木衣肩上的正面，再从这张被认可的图派生出严格侧面。

04 The “Before” T-shirt from Molimao’s catalog. These photographs establish what the product actually looks like.

04 来自 Molimao 目录的 “Before” T 恤。这些照片确定产品实际上长什么样。

Generating the profile from the accepted front image helped retain scale, light and hanger position. We used a flat green background to make separation easier. For a garment containing green, the backing or masking strategy must change.

从被认可的正面图生成侧面，有助于保住比例、光线和衣架位置。我们用了平整的绿色背景，好分离。如果衣服本身含绿色，背景或蒙版策略就必须改。

05 基于目录照片生成的视图。请对照原图检查印花准确性、轮廓和颜色。

For video, the profile becomes the first frame and the front view the last frame: the two endpoints the model should connect. We checked the pair for matching apex, size, color and frame clearance. The wire stayed outside the generation; rendering it separately avoided a fragile thin edge in every frame.

做视频时，侧面成为首帧，正面成为末帧：也就是模型应该连接的两个端点。我们检查这一对是否在顶点、尺寸、颜色和画面留白上匹配。挂线留在生成之外；单独画它可以避免每一帧都出现脆弱的细边。

API 成了开发流程的一部分

We connected LTX API to the workflow in Codex. A local script sent the two images and motion prompt to LTX-2.5 Pro, saved the job ID, checked completion and downloaded the video into the project. I approved the spending limit and selected the takes. The website itself never calls the model.

我们把 LTX API 接到了 Codex 里的工作流。一段本地脚本把两张图和运动提示词发给 LTX-2.5 Pro，保存任务 ID，检查是否完成，再把视频下载进项目。我批准了支出上限，并挑选镜头。网站本身从不调用模型。

Codex images + prompt → LTX API video generation → Project folder MP4 + job receipt.

Codex 图像 + 提示词 → LTX API 生成视频 → 项目文件夹中的 MP4 和任务回执。

The source requests used six seconds, 1080p and 50 frames per second, without audio. The constraint was one smooth quarter-turn with a locked camera and consistent light. Generation length and interaction duration are different settings; the UI would not make someone wait six seconds.

源请求用的是 6 秒、1080p、每秒 50 帧，没有音频。约束是一次平滑的四分之一圈旋转，相机锁定、光线稳定。生成时长和交互时长是不同的设置；界面不会让人等六秒。

How your agent connects the video model: The repository includes an LTX connector and an example request. Your agent prepares the settings, helps you connect your account privately, and shows the estimated cost before generating. The connector saves a job receipt so an interrupted request can be resumed. The LTX API documentation is linked in the repository for the agent to check.

你的 agent 如何连接视频模型：仓库里有一个 LTX 连接器和一个示例请求。你的 agent 会准备设置，帮你私密地连接账号，并在生成前显示预估费用。连接器会保存任务回执，中断的请求可以恢复。仓库里链接着 LTX API 文档，供 agent 查阅。

You review the two images and approve a spending limit. The agent handles the request, downloads the video and prepares the animation files. The generated file is intermediate material. We still have to choose a useful interval, remove the backing and test the turn in its actual controller.

你审看这两张图，并批准支出上限。agent 处理请求、下载视频并准备动画文件。生成的文件只是中间素材。我们还要选出有用的区间，去掉背景，并在实际控制器里测试这次旋转。

把衣服从背景里分离出来

To place the rotating garment on the site’s rail, we removed the green background from each frame. The transparent result could sit over the page while staying attached to one suspension point.

为了把旋转的衣服放到网站的衣杆上，我们从每一帧去掉绿色背景。透明结果可以叠在页面上，同时始终挂在同一个悬挂点上。

  1. Select and sample the turn. Extract the useful interval and retain a compact sequence of frames, including its exact endpoints.
    选择并取样这次旋转。抽出有用的区间，保留一段紧凑的帧序列，包括精确的两端。
  2. Build the alpha mask. Identify the flat backing and soften the boundary. Alpha describes each pixel's transparency.
    建立 Alpha 蒙版。识别平整背景，柔化边界。Alpha 描述每个像素的透明度。
  3. Remove color spill. Clean green contamination from partly transparent edges, then inspect sleeves, hem and wood against contrasting backgrounds.
    去除溢色。清理半透明边缘上的绿色污染，再在对比背景下检查袖口、下摆和木头。
  4. Register the suspension point. Keep the wooden apex at one screen position. Apply one shared crop and scale across the sequence; independent crops would make the garment jump.
    对齐悬挂点。让木头顶点停在屏幕上的同一个位置。对整段序列使用同一套裁切和缩放；各自裁切会让衣服跳动。
  5. Pack the frames. Store them in a WebP atlas (a single image containing a grid of animation frames), with a small file describing the grid.
    打包帧。把它们存进 WebP 图集（一张包含动画帧网格的图），再配一个描述网格的小文件。

Most rail items used 30 frames; some retained more. A fixed wire in the interface connects the rail to the apex. Its position does not change while the shoulders turn underneath.

衣杆上的大多数单品用了 30 帧，有些保留了更多。界面里有一根固定的线把衣杆连到顶点。衣肩在下面转动时，它的位置不变。

Try the dark background: it reveals pale halos. Orange helps expose green residue. The green Tag Green hoodie needed its own treatment so the key would not remove fabric with the backing. We adjusted the background removal for individual garments.

试试深色背景：它会露出浅色光晕。橙色有助于暴露残留的绿色。绿色的 Tag Green 连帽衫需要单独处理，以免抠像把面料和背景一起去掉。我们为单件衣服调整了去背。

把六秒影像做成可响应的悬停

We now had six-second video files. Waiting for each one to play would make browsing slow. The next problem was to complete the same turn in a fraction of a second and allow interruption at any point.

这时我们有了六秒的视频文件。若等每一段播完，浏览就会很慢。下一个问题是：在几分之一秒内完成同一次旋转，并允许在任意时刻被打断。

The site chooses a cell from the atlas according to a small timeline. Hover moves its playhead toward the front; leaving reverses it from the current position. Hovering again during the return changes direction without restarting at frame zero.

网站按一条短时间线从图集里选取单元格。悬停时播放头移向正面；离开则从当前位置反向转回。在转回过程中再次悬停，会改变方向，而不是从第 0 帧重来。

Speed removed the wait, but the first accelerated version felt abrupt. I refined the intent delay, acceleration, braking and direction changes. The final adjustment softened the outer 30% of the motion curve while retaining its middle and overall duration.

速度去掉了等待，但第一版加速后的运动感觉很突兀。我调整了意图延迟、加速、刹车和转向。最终的调整柔化了运动曲线外侧 30%，同时保留了中段和总时长。

07 Interactive reconstruction of the two controller settings on identical frames of the “Before” T-shirt. Duration is unchanged. Slow playback makes the subtle difference easier to inspect. This comparison widget is on the original page.

07 用 “Before” T 恤的相同帧，交互式重建两种控制器设置。时长不变。慢放更容易看清细微差别。这个对比控件在原页上。

The neighboring garments also move with smooth acceleration, at full opacity. Dimming them had made the scene feel less physical, so I removed it. At rest, the selected item holds the timeline's endpoint. Swapping in an unrelated PNG after the turn could introduce a visible jump in fabric or hanger thickness.

相邻衣物也会平滑加速移动，并且保持完全不透明。把它们变暗会让场景少了实物感，所以我去掉了变暗。静止时，被选中的那件停在时间线的终点。如果在转完后换上一张无关的 PNG，面料或衣架厚度可能会出现可见的跳动。

一段好视频，仍可能做不成界面动画

A take can look convincing in a player and become unstable after trimming, acceleration and easing (the curve that controls how motion starts and stops). Sideways drift, rocking or changing folds become much more visible at hover speed.

一个镜头在播放器里看起来很可信，但在裁剪、加速和缓动（控制运动如何起止的曲线）之后，却可能变得不稳。横向漂移、晃动或褶皱变化，在悬停速度下会明显得多。

We therefore tested each take at source speed and in the interface, including partial turns, reversal and repeated pointer changes. After acceleration, the Cupid tee and purple M Bird tee visibly rocked. Grow and Forora showed similar problems later. Once the interaction timing felt right, I kept it and replaced the unstable footage.

因此，我们在源速度和界面里都测试了每个镜头，包括部分旋转、反向，以及反复改变指针。加速之后，Cupid T 恤和紫色 M Bird T 恤明显在晃。Grow 和 Forora 后来也出现了类似问题。一旦交互节奏感觉对了，我就把它固定下来，并替换不稳的影像。

https://amirmushich.com/publications/interactive-clothing-hero/assets/mbird-first.mp4

We regenerated clips with unstable movement and trimmed takes that contained a clean turn. For Cupid, we kept the clean forward turn from 2.8 to 4.5 seconds of a new take. For Forora, we used the early interval before extra rotation. Background residue and bright wooden-edge flashes were processing problems, handled separately.

我们对运动不稳的片段重新生成，并裁出包含干净旋转的镜头。对 Cupid，我们保留了新镜头里 2.8 到 4.5 秒那段干净的正向旋转。对 Forora，我们用了额外旋转出现之前的前段。背景残留和木头边缘的亮闪是后期处理问题，另行处理。

The acceptance criterion was a stable, recognizable product throughout the interaction. Easing changes when frames appear. It cannot restore a distorted print or remove oscillation already recorded in them.

验收标准是：在整个交互过程中，产品稳定且可辨认。缓动只改变帧出现的时机。它不能修复已经变形的印花，也去不掉已经录进这些帧里的振荡。

在手机上把浏览和选中分开

Desktop hover depends on a pointer. On touch screens, we needed a clear distinction between browsing and opening a product. I kept one garment centered, with neighboring profiles visible. Swiping changes the selection; after settling, the central garment turns.

桌面上的悬停依赖指针。在触屏上，我们需要把浏览和打开产品清楚分开。我让一件衣服居中，旁边能看见相邻的侧面。滑动改变选择；停稳后，中间那件转过来。

  • Swipe to browse: The rail follows the gesture, then settles the nearest garment in the center.
    滑动浏览：衣杆跟随手势，然后把最近的一件停在中间。
  • Tap to inspect: A separate product view shows the available sides. Closing it returns to the same selection.
    点按查看：单独的产品页展示可用的各面。关闭后回到同一选择。
  • Change your mind: Reversal should remain continuous; a completed swipe should not also open a product.
    改变主意：反向应保持连续；一次完成的滑动不应同时打开产品。

解决加载问题

After expanding to ten products and sharing a public demo, we hit a cold-load problem. On a connection around 10 Mbps, profile stills appeared before the animations were ready. The interface looked usable, but hover did nothing for ~5 seconds in my initial test.

扩展到十件产品并公开演示之后，我们碰到了冷启动加载问题。在大约 10 Mbps 的连接上，侧面静图会先出来，动画还没准备好。界面看起来能用，但我最初测试时，悬停大约 5 秒都没有反应。

A loading screen with real progress showed when the collection was ready. We then reduced the size of the image sheets containing the animation frames and bundled them into one download. The number and dimensions of the frames stayed the same, and we checked the transparent edges after compression.

带真实进度的加载屏会显示合集何时就绪。随后我们缩小了包含动画帧的图片表，并把它们打成一次下载。帧的数量和尺寸保持不变，压缩后我们检查了透明边缘。

把入门包交给你的 AI agent

To make this workflow available without distributing a clothing brand's catalog, I repeated it with two original prints: an alpine landscape on a white T-shirt and black card artwork on a pastel-pink T-shirt. These generated garment concepts are the running example in the starter. The Molimao visuals in this article remain the record of the original experiment.

为了在不散发某个服装品牌目录的情况下提供这套流程，我用两件原创印花重做了一遍：白色 T 恤上的高山风景，以及粉彩 T 恤上的黑色卡片图案。这些生成的服装概念是入门包里正在运行的示例。文章中的 Molimao 视觉仍是原实验的记录。

The image tool produced the cotton bases and matched views. I kept the original graphics as the print source.
